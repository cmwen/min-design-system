# Demo asset provenance

The temporary Min Wen branding mark was fetched on 11 October 2026 from [cmwen.dev/favicon.svg](https://cmwen.dev/favicon.svg), at the user's explicit request to use their site's icon. The original is retained in `public/cmwen-mark.svg`. Inline demo copies retain the geometry and use `currentColor` so the mark follows Forest & Fern's theme; movement is supplied by the reusable CSS.

This mark is a demo branding asset, not part of the MIT CSS package. It is excluded from the npm tarball. Consumers should supply their own logo. The site's favicon remains the existing Forest & Fern mark.

Nunito licensing is documented separately in `public/fonts/OFL.txt`.
